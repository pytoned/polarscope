Why Polarscope

Everything you need to know your data

One function call. Six kinds of insight. Rendered as a table you'll actually want to look at.

🔬

One-call xray()

Summary statistics for every column by default, or include="all" for mixed types — all in a single inspection table.

📈

Deep stats, on demand

Flip expanded=True for normality & uniformity tests, outlier metrics, usability flags and correlation details.

🌸

Great Tables output

Beautiful tables with histogram nanoplots and data bars — or pass great_tables=False to get a plain Polars DataFrame.

🐻‍❄️

Polars-native

Core data handling is implemented entirely in Polars. Fast, typed, and no Pandas required.

🧹

Cleaning utilities

clean_column_names, convert_datatypes and drop_missing to tidy frames before you analyze them.

📊

Plots & datasets

Correlation, missing-value, distribution and categorical plots — plus built-in titanic and diabetes datasets to play with.

Quick start

Up and running in seconds

Install & x-ray

  • Works with any Polars DataFrame or built-in dataset
  • Targeted correlations via corr_target
  • Choose your outlier method: IQR, percentile or z-score
  • Render rich Great Tables or raw Polars output
Install from PyPI
analysis.py
import polars as pl
import polarscope as ps
from polarscope.datasets import titanic

# load a built-in dataset (or your own)
df = titanic()

# the whole library, in one call
ps.xray(df)

# go deeper: tests, outliers, correlations
ps.xray(
    df,
    expanded=True,
    corr_target="Survived",
    outlier_method="iqr",
)
